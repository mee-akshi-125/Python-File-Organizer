# Python File Organizer

## Description

A Python automation script that automatically organizes files into folders based on their file types.

## Features

* Organizes Images
* Organizes PDFs
* Organizes Documents
* Organizes Videos
* Moves unknown files to Others folder

## Technologies Used

* Python
* os module
* shutil module

## How to Run

1. Run the script:
   python file_organizer.py

2. Enter the folder path.

3. Files will be organized automatically.

## Output

The program creates folders and moves files into their respective categories.
